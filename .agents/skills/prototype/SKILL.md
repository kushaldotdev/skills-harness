## Pack rules

- Inside a `rigor` run there is no user to ask which question is being answered. Take it from the brief or the open decision that triggered the prototype, and log it ([AFK.md](../rigor/AFK.md)).
- Upstream names resolve through [the name index](../rigor/references/INDEX.md).
