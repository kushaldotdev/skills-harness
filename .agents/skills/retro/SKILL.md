# Retro

## Modes

| Mode | When | Body |
|---|---|---|
| retro (default) | After a build, especially one that went sideways | [retro](references/matt/retro/retro.md) |
| reflect | Three parallel reviewers over the transcript; each learning routed to a skill edit | [reflect](references/pstack/reflect/reflect.md) and its references |
| correct | Make a repeated agent mistake impossible: architecture, then types, lint, test, docs last | [correct](references/pstack/correct/correct.md) |
| automate me | Capture the user's working style as a personal mode skill | [automate-me](references/pstack/automate-me/automate-me.md) |

Principle: [encode-lessons-in-structure](references/pstack/principle-encode-lessons-in-structure/principle-encode-lessons-in-structure.md) whenever an instruction is written a second time.

## Pack rules

- Retro is a human-present session. `reflect` waits for approval before applying edits; that wait is intended.
- Edits that would land in a vendored body go to the host's SKILL.md or `rigor` files instead: copies under `references/matt/` and `references/pstack/` are regenerated by the pack build and any edit there is overwritten.
- Transcript locations per harness are in [harness notes](../rigor/harness/). Upstream names resolve through [the name index](../rigor/references/INDEX.md).
