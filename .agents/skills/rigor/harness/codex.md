# Codex CLI

Verified against the Codex build-skills, AGENTS.md and subagents docs (2026-10-20); codex-cli 0.163.0 installed.

- **Skills.** Discovers `.agents/skills/` from the cwd up to the repo root. Invoke with `$<name>` or `/skills`. Hidden skills are hidden through `agents/openai.yaml` `policy.allow_implicit_invocation: false` (generated by the build). Whether frontmatter `disable-model-invocation` is honored is undocumented.
- **Instructions.** Reads `AGENTS.override.md`, then `AGENTS.md`. Does not read `CLAUDE.md`.
- **Children.** Subagents are on by default and inherit skills. Send the absolute-path packet anyway.
- **Parallel.** Request several subagents at once; Codex waits until all results are back (no documented async).
- **Wait / loop.** No documented wake mechanism. End at a checkpoint barrier with the resume command (`$rigor resume <slug>`).
- **Model roles.** Custom agents in TOML (`model = ...`).
- **Transcripts.** `~/.codex/sessions/YYYY/MM/DD/` (seen locally; layout undocumented).
- **Fallbacks.** Blocking waves sized to the unit budget; babysit and watchers degrade to one poll per session.
